#About

This project has a graphic interface showing a 3x3x3 cube where up to three players (computer or Human) can play additionally their can be two players, as the game settings are completely customizabale

#Minimax Algorithem

the minimax algorithm is used for the the computer players and its max depth can be changed in the game settings to affect its difficulty. Alpha Beta pruning was also used to make the computer player more efficent so its moves wouldn't take so long.
